# 上海地铁客流量 2017 描述性分析报告

> 数据：`metroData_InOutFlow.csv`（主）、`stationInfo.csv`、`天气&工作日/shanghai_weatherHourly.csv`、`天气&工作日/workday_calendar.csv`
> 数据来源：MetroFlow 开源数据集（GitHub https://github.com/Ariza-Sun/MetroFlow ；figshare DOI https://doi.org/10.6084/m9.figshare.33436675 ），MIT License，引用 Sun et al., Scientific Data 12 (2025)
> 时间范围：2017-05-01 ~ 2017-08-31，共 123 天；站点 302 个
> 说明：本报告为数据描述性分析，用于刻画数据基本特征、质量与规律，为后续建模与多源融合提供依据。

---

## 一、数据概览

| 项目 | 内容 |
|---|---|
| 记录数（行） | 3,788,892 |
| 字段数（列） | 13 |
| 日期范围 | 20170501 ~ 20170831，共 123 天 |
| 站点数 | 302（站点ID 112~2057，不连续） |
| 时间粒度 | 06:00 ~ 23:00，每 10 分钟一片，每日 102 片 |
| timeslot 字段 | 0 ~ 12545，全期连续时间片索引（天序 × 102 + 日内片序） |
| 数据规模 | 约 207.4 MB |

**字段含义**：`inFlow`/`outFlow` 为进出站客流总量；`C`/`HBO`/`NHB` 前缀分别代表通勤（Commuting）、基于家-其他（Home-Based Other）、非基于家（Non-Home-Based）三类出行目的分量，后缀 `in`/`out` 表示进/出站方向。

| 类型 | 天数 | 日均总客流（人次） | 早高峰（8:00） | 晚高峰（18:00） | 峰值小时 |

- 工作日日均客流约为非工作日的 1.55 倍，工作日/非工作日是本项目最关键的分组维度之一。

## 八、小结

1. **数据质量高**：无缺失、无重复、进出站闭合配平，可直接用于分析；仅 6 个不完整日期需剔除，最终有效 117 天。
2. **时间规律清晰**：全网客流呈典型双峰（早高峰 8:00 最强）；工作日以通勤双峰为主，非工作日无早高峰、客流平缓，两者日均差约 1.55 倍。
3. **空间高度集中**：少数市中心商业区与交通枢纽站点占据主导，客流呈长尾右偏分布；站点功能（通勤型 vs 对外交通/休闲型）可从出行目的占比清晰区分。
4. **出行目的可分解**：通勤约 32%，为非基于家约 38.5%、家-其他约 29.5%，为理解客流结构提供了丰富维度。
5. **天气影响有限**：降雨与高温对客流有轻微负向影响，但远小于工作日/节假日效应，需作为控制变量而非主导因素。
6. **建议后续方向**：① 工作日/节假日分层建模；② 结合站点周边 POI/用地结构解释站点间客流差异；③ 利用 C/HBO/NHB 分量构建出行目的模型，支撑产业结构与通勤分析。
