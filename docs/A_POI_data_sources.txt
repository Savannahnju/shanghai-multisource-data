## 2. 各数据源详细说明

### 2.1 2025年上海市高德POI兴趣点数据

| 项目 | 内容 |
|---|---|
| 来源 | CSDN 资源购买页：https://download.csdn.net/download/yugnahz/93265644 ；实际下载渠道为百度网盘：https://pan.baidu.com/s/1d6VA_MNgcsE7MJHztYBvvA?pwd=y3zv |
| 获取方式 | 付费购买（需要全量 POI 做上海市各地区产业结构等分析，个人用户直接调用百度/高德地图 API 全量获取预计需 1–2 周且时间成本不确定，故购买现成全量数据） |
| 数据类型 | CSV（UTF-8 带 BOM）+ SHP（Shapefile 点要素，投影为 WGS84 地理坐标系，.cpg 为 UTF-8） |
| 原始规模 | 1,422,977 条记录。CSV：276,555,528 字节（约 263.7 MB）；SHP：.dbf 2,259,687,990 字节（约 2.15 GB）、.shp 39,843,456 字节（约 38 MB）、.shx 11,383,916 字节（约 10.9 MB）；合计约 2.4 GB |
| 时间范围 | 2025 年（数据时间基准，代表截至 2025 年最新采集、审核与发布的实体位置与属性信息，无具体起止日期） |
| 采集时间 | 2025 年（高德官方采集/发布时间）；本地下载时间约 2026-08 |
| 许可/使用说明 | CSDN 付费资源，仅限课程研究使用；全部记录已脱敏，不包含个人身份信息、敏感经营数据及涉密单位坐标，符合《中华人民共和国数据安全法》《个人信息保护法》《地图管理条例》 |
| 主要字段 | ID,名称,类型码,大类,中类,小类,省份,城市,区县,经度_GCJ02,纬度_GCJ02,经度_WGS84,纬度_WGS84,电话,地址 |
| 跨源关联字段 | 经度_GCJ02/纬度_GCJ02、经度_WGS84/纬度_WGS84、区县/地址、类型码（大类/中类/小类）、名称 |
| 可关联数据源 | B/C/D/E 的区划、地铁、空气质量、气象、绿地等数据（具体待清洗/融合阶段确认） |
| 关联方式 | 空间（经纬度空间 Join）/ 实体（名称、地址）/ 语义（POI 类型码→产业分类） |
| 采集脚本 | 无（付费购买获取，未使用爬虫） |
| 备注 | ① 本文件夹原名为"上海市百度地图POI数据"（原命名系下载渠道为百度网盘所致），已于 2026-10-16 重命名为"上海市高德地图POI数据"，本清单以数据来源说明中的"2025年上海市高德POI兴趣点数据"为准；② 实测数据质量：`城市` 列全部为"021"（电话区号）、`区县` 列全部为"上海市"，无真实区级信息，需从地址字段解析或与区划数据空间连接；③ 分类体系实测：一级大类 24 个（来源说明写 23，以实测为准）、中类 237 个、小类 3768 个；④ 同时提供 GCJ02 与 WGS84 两套坐标，GCJ02 可直接对接百度、高德、腾讯等平台；⑤ 电话字段缺失值记为 `[]`（缺失率约 68%）；⑥ 来源说明宣称位置精度优于 5 米、属性完整率 98.7% 以上（待清洗阶段抽验） |

## 5. 数据规模与合规说明

- 本成员数据源总原始规模：约 2.4 GB（CSV 约 263.7 MB + SHP 约 2.2 GB）
- 是否满足单源≥200MB：是（仅 CSV 一项约 263.7 MB 即已满足）
- 是否涉及个人敏感信息：否（数据已脱敏）
- 是否遵守服务条款与robots：不适用（付费购买，未爬取）
- 其他说明：购买原因为个人 API 全量获取时间成本高（预计 1–2 周）；数据时间基准为 2025 年；文件夹原名为"百度地图"，已重命名为"高德地图"，见 2.1 备注
