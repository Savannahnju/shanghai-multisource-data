# B · AI 使用情况说明（AI Usage）

> 研究问题（Q1）：**城市环境质量是否与地铁客流量（2017 年）有关？**
> 负责人：B。本文件如实记录 B 在研究全流程中对 AI 的使用方式与边界，供最终报告「AI 使用情况」部分引用。

---

## 1. 使用的 AI 工具

| 项 | 内容 |
|---|---|
| 工具 | Anthropic Claude（经 Claude Code CLI 使用） |
| 使用方式 | 交互式辅助：起草、调试、核验、排版 |
| AI 未参与 | 研究问题设计、数据合规判断、最终结论的学术责任界定 |

## 2. 分环节使用情况

| 环节 | AI 辅助内容 | 人工负责内容 |
|---|---|---|
| 数据源梳理 | 起草 data_source 文档结构、整理字段含义与跨源关联字段 | 数据源选择、开源数据下载、许可/合规核对、MD5 校验 |
| 数据清洗 | 按团队标准生成/调试清洗与融合脚本（`fuse_environment_metro.py`） | 清洗规则制定（依据 `E_cleaning_standard.md` 与课程要求）、剔除规则核定 |
| 描述性分析 | 统计计算、表格与描述性统计报告起草 | 结果核验、口径确认（如日均/强度定义） |
| 数据分析 | 编写分析脚本 `analyze_q1.py`（Pearson 相关、OLS 回归、稳健标准误） | 模型设定与变量选择、结果解读与把关 |
| 可视化 | 图表生成（配色、字体、布局，matplotlib） | 图意审核、是否准确表达结论 |
| 报告撰写 | 起草数据源清单、描述性分析、关联说明、分析报告与文档排版 | 全文审校、结论与局限的最终定稿 |

## 3. 使用边界与说明

- 所有脚本输入路径参数化、可一键复现；
- 所有统计量与图表均经人工与原始数据交叉核对；
- AI 仅作为辅助工具，不代替 B 对数据合规性、方法合理性与最终结论的学术责任。
