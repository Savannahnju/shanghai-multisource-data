## 2. 时间跨度

- **数据本身不含任何时间字段**（无采集时间戳、更新时间等列），无法从数据内部确认时间跨度。
- 据来源说明，数据**时间基准为 2025 年**，代表截至 2025 年最新采集、审核与发布的 POI 状态，属**单期横截面快照**，而非时间序列。
- 影响：本项目无法对该数据做时间趋势/时序分析；与其他成员数据的关联只能按"2025 年快照"做语义对齐，无法按日期字段 Join。

## 5. 异常情况

| 异常项 | 实测结果 | 影响与建议 |
|---|---|---|
| 坐标一致性 | 两套坐标逐条互验：GCJ02−WGS84 经度差 0.0041~0.0047（均值 0.0045）、纬度差 −0.0024~−0.0017（均值 −0.0020），与 GCJ02 在上海地区的公开偏移规律完全吻合，**异常 0 条** | 双坐标可放心使用；与外部 WGS84 数据融合时用 `经度_WGS84/纬度_WGS84`，与地图平台对接用 GCJ02 |
| 坐标离群 | 落在粗略上海市范围外 2 条 | 清洗时用区划边界剔除或人工核查 |
| ID 重复 | 唯一值 1,340,839，重复 82,138 条（5.77%） | 与来源说明"唯一标识"不符；融合/去重前先按 ID 查重 |
| 城市列错位 | 全部为 "021"（电话区号） | 该字段不可用作城市名 |
| 区县列降级 | 全部为 "上海市"，无区级信息 | 分区统计必须空间连接（地址关键词仅覆盖 11.56%） |
| 类型码一对多 | 11 个类型码对应多组（大类,中类,小类），影响 190,040 条（13.36%）；部分类型码值含 `\|` 多码拼接（如 "020000\|030000"） | 分类统计一律以"大类/中类/小类"文字列为准，不要用类型码做映射 |
| 电话格式异常 | 2,687 条（占非缺失电话的 0.59%）含数字、分号、括号之外的字符 | 清洗时正则校验或直接置空 |
| 名称过短 | 46 条名称长度 ≤1 个字符（如单字店名） | 人工核查或按低置信处理 |
| 地址含已撤销区名 | 南汇 1,685、闸北 243、卢湾 120（合计 2,048 条） | 说明部分地址历史口径较旧；解析时需做区名归并映射 |

## 6. 小结

1. **规模充足**：142 万余条、约 2.4 GB，满足单源 ≥200 MB 要求，覆盖全上海。
2. **横截面快照**：无时间字段，仅能做 2025 年时点的空间/结构分析，不能做时序分析。
3. **分布特点**：POI 高度集中于中心城区；一级大类头部集中（前 5 类占 65.93%），且"地名地址信息"类（门牌/楼栋号）占比最大，产业分析时应单独处理。
4. **主要质量问题**：区县字段失效（分区需空间连接）、电话缺失 67.98%、ID 重复 5.77%、类型码一对多（13.36% 记录受影响）。
5. **清洗优先级建议**：① 按 ID 去重；② 用区划边界对 POI 做空间连接补区县；③ 分类以文字类目列为准；④ 与外部数据融合统一用 WGS84 坐标；⑤ 电话字段按高缺失率处理（不纳入核心分析）。
