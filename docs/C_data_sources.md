## 2. 来源与许可说明

- **数据形态**：文件由 shapefile（shp）转换而来，属性中保留了 ArcGIS 生成的 `Shape_Leng`、`Shape_Area` 字段；`city`/`citycode`/`adcode` 字段结构与高德（AMap）行政区划数据的字段风格一致。原始 shp 的最初发布机构与确切版本号暂缺，已列入待补充项。
- **许可/使用说明**：行政区划边界数据版权归原发布机构所有，本组仅在课程作业范围内用于教学与学术分析，不用于商业用途，不对外再分发完整数据（仓库中仅上传抽样样本）。
- **版本推断依据**：区级数据含 `崇明区（310151）`，且不含已撤销的闸北（310108）、南汇（310119）、卢湾（310103）等代码，可判断数据为 2016 年崇明撤县设区之后的行政区划版本。
