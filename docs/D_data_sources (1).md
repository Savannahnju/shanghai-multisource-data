## 2. 各数据源详细说明

### 2.1 环境质量数据（主数据源）

- **来源**：上海市生态环境局（各区降尘量、PM2.5 月均浓度、空气质量月报，数据提供方待确认）
- **获取方式**：数据文件直接提供
- **数据类型**：xlsx（3 个 sheet）
- **原始规模**：72,007 字节（约 70 KB）；「2017年降尘量月度对比」16 区 × 12 月、「2017年PM2.5月度对比」16 区 × 12 月、「2024-2025年上海市空气质量」384 行 × 7 列
- **时间范围**：2017 年（降尘量、PM2.5，逐月）；2024–2025 年（空气质量，逐月）
- **采集时间**：2026-10
- **许可/使用说明**：政府公开数据，需注明来源
- **主要字段**：① 2017 降尘量：地区 + 1~12 月（t/km²·月，单位待确认）；② 2017 PM2.5：地区 + 1~12 月（μg/m³）；③ 2024–2025 空气质量：年份、月份、区名、AQI优良率(%)、PM2.5、O₃、道路PM10（μg/m³）
- **跨源关联字段**：区名（空间/实体关联）、年份 + 月份（时间关联）
- **可关联数据源**：植被栅格（按区名 + 分区统计）、年鉴绿地面积/人口密度（按区名）、行政区划 shp（按区界）
- **关联方式**：实体（区名）、空间（区界）
- **采集脚本**：无（直接提供）
- **备注**：① 三张 sheet 均无缺失、无重复，16 区口径一致；② 2017 降尘量奉贤区 11 月 = 12.5、12 月 = 9.3 为可疑高值，需核对；③ 「道路PM10」的"道路"前缀所指口径需确认；④ 2024–2025 空气质量为本研究 Q2 的**主用**环境质量数据，2017 两张 sheet 亦纳入描述性统计但非 Q2 关联分析时段

### 2.2 植被数据（主数据源）

- **来源**：上海城市绿地植被韧性数据集（2001–2022, V1.0），数据论文《全球变化数据学报》2025, 9(1): 52–58，DOI 10.3974/geodp.2025.01.07；数据 DOI 10.3974/geodb.2024.12.04.V1
- **获取方式**：开放数据集下载
- **数据类型**：TIF 栅格 + shp
- **原始规模**：约 1.7 MB（解压后）；GREEN_R / STL_AR1 / V2_AR1 / V2_VAR 四个栅格 + 研究区 shp + 数据论文
- **时间范围**：2001–2022 汇总（静态快照，每像元一个值，无逐年维度）
- **采集时间**：2026-10
- **许可/使用说明**：需按数据论文引用（DOI 10.3974/geodp.2025.01.07）
- **主要字段**：GREEN_R（绿地占比 %）、STL_AR1 / V2_AR1 / V2_VAR（植被韧性，无量纲）、栅格像元坐标
- **跨源关联字段**：栅格坐标（空间关联，按区界做分区统计）
- **可关联数据源**：环境质量、年鉴（按区名，经分区统计后）、行政区划 shp（按区界）
- **关联方式**：空间（栅格 × 区界分区统计）
- **采集脚本**：无（开放数据下载）
- **备注**：① 250 m 格网、16,745 像元，WGS84 / EPSG:4326；② 基于 2001–2022 MODIS NDVI、临界慢化理论，三个韧性指标为统计系数、允许为负值；③ 为静态快照，与 2024–2025 环境质量存在约 2 年时间错配

### 2.3 统计年鉴（辅助数据源）

- **来源**：上海市统计年鉴（2024 年）
- **获取方式**：数据文件直接提供
- **数据类型**：xls
- **原始规模**：约 110 KB（各区绿地面积、各区人口密度等 4 个 xls）
- **时间范围**：2024 年，16 区
- **采集时间**：2026-10
- **许可/使用说明**：政府公开数据
- **主要字段**：地区、绿地面积（公顷）、公园绿地面积（公顷）、人口密度（人/平方公里）等
- **跨源关联字段**：区名
- **关联方式**：实体（区名）
- **采集脚本**：无
- **备注**：辅助数据源，用于 Q2 的控制变量（人口密度）与植被数据的交叉印证

### 2.4 行政区划 shp（辅助数据源）

- **来源**：上海市行政区划（区级 / 乡镇级）
- **获取方式**：数据文件直接提供
- **数据类型**：geojson + shp
- **原始规模**：约 6.9 MB（区级 + 乡镇级）
- **时间范围**：静态
- **采集时间**：2026-10
- **许可/使用说明**：政府公开数据
- **主要字段**：区界 / 乡镇界多边形、区名、adcode
- **跨源关联字段**：区名、区界（空间）
- **关联方式**：空间（栅格分区统计、点面相交）
- **采集脚本**：无
- **备注**：辅助数据源，用于植被栅格分区统计与各区空间对齐

## 3. 跨源关联字段汇总

- **环境质量**（区名）↔ **植被栅格分区统计结果**（区名）：实体/空间，按区对齐
- **环境质量**（区名）↔ **年鉴**（区名）：实体，按区对齐
- **植被栅格**（栅格坐标）↔ **行政区划 shp**（区界）：空间，分区统计
- **环境质量**（年份、月份）↔ 组内其他时间数据源：时间，按年/月对齐

## 5. 数据规模与合规说明

- **本子项目数据源总原始规模**：约 8.8 MB（环境质量 70 KB + 植被 1.7 MB + 年鉴 110 KB + 区划 6.9 MB）
- **是否满足单源≥200MB**：否（本子项目均为中小规模/辅助数据，非主数据源）
- **是否涉及个人敏感信息**：否

- **其他说明**：① 环境质量数据 2017 与 2024–2025 两时段并存，Q2 主用 2024–2025；② 植被为 2001–2022 静态快照，与 2024–2025 环境质量存在约 2 年时间错配；③ 「道路PM10」「降尘量单位」需与数据提供方确认
