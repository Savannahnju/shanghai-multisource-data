## 2. 各数据源详细说明

### 2.1 上海空气质量历史数据集（zenedo，主数据源）

- **来源**：Zenodo 开放数据集「Dataset: Air Quality Dataset for Shanghai」（id: nitirajkulkarni/shanghai-cn-1796236），提供上海历史空气质量时间序列与城市元数据；字段命名与 Open-Meteo 空气质量历史再分析一致
- **获取方式**：开放数据集直接下载（非 API / 非爬取）
- **数据类型**：CSV（UTF-8）；另附 city_info.csv、dataset-metadata.json、README.md
- **原始规模**：`air_quality_historical.csv` 1,297 行 × 12 列，233,227 字节（约 228 KB）；`city_info.csv` 158 字节
- **时间范围**：2022-08-01 ~ 2026-02-17，日粒度，共 1,297 天（连续无缺）
- **采集时间**：2026-10
- **许可/使用说明**：CC0-1.0（公有领域，可自由使用、修改、分发）
- **主要字段**：date、pm10、pm2_5、carbon_monoxide（CO）、nitrogen_dioxide（NO₂）、sulphur_dioxide（SO₂）、ozone（O₃）、aerosol_optical_depth（AOD）、dust、uv_index、us_aqi、european_aqi
- **跨源关联字段**：`date`（时间关联）、城市名 / 经纬度（空间关联）
- **可关联数据源**：E 的统计年鉴气象（按月对齐）、行政区划 shp（空间对齐）、生态环境局样本（同日对比校验）
- **关联方式**：时间（按日 / 月聚合）、空间（城市级经纬度）
- **采集脚本**：无（开放数据直接下载）
- **备注**：① 为上海全市单条日序列，无分区 / 站点拆分，空间分析需借助区划边界或补充站点级数据；② 污染物单位约 μg/m³（CO 亦为 μg/m³，约 1.2 mg/m³ 量级），AOD / UV / AQI 无量纲，单位口径需在清洗阶段与元数据核对；③ 前 3 天（2022-08-01 ~ 08-03）所有污染物整行缺失，us_aqi / european_aqi 缺前 4 天，其余缺失率仅 0.23%；④ 无负值、无重复日期、无缺日；⑤ 颗粒物冬高秋低、O₃ 夏高冬低，符合上海季节特征

### 2.2 上海市生态环境局·空气质量历史数据查询（辅助数据源）

- **来源**：上海市生态环境局（环境质量月报 / 空气质量历史数据查询页面）
- **获取方式**：网页查询结果导出（文件后缀 .xls，实为 HTML 表格）
- **数据类型**：HTML 表格
- **原始规模**：11 行 × 11 列，7,284 字节（约 7 KB）
- **时间范围**：2026-09-18 ~ 2026-09-28，日粒度，共 11 天
- **采集时间**：2026-10
- **许可/使用说明**：政府公开数据，需注明来源
- **主要字段**：序号、日期、PM2.5分指数、PM10分指数、O3分指数、SO2分指数、NO2分指数、CO分指数、AQI、质量评价、首要污染物
- **跨源关联字段**：日期（时间关联）
- **可关联数据源**：zenedo 空气质量数据集（同日对比校验）
- **关联方式**：时间（按日期）
- **采集脚本**：无（网页导出）
- **备注**：① 小样本（11 天），为中国 AQI 口径的分指数、质量评价与首要污染物，可作 zenedo 数据口径校验的参照；② 样本 AQI 范围 38 ~ 87，优 5 天、良 6 天，良天首要污染物均为 O₃；③ 与 zenedo 的 US-AQI / EU-AQI 断点不同，清洗阶段需统一 AQI 口径

## 3. 跨源关联字段汇总

- **zenedo 空气质量**（`date`）↔ **E 统计年鉴气象**（月份）：时间关联，空气质量日序列按月聚合后与气象月指标对齐
- **zenedo 空气质量**（城市名 / 经纬度）↔ **行政区划 shp**（区界 / 乡镇界）：空间关联，城市级点位与区划边界关联
- **生态环境局 xls**（日期）↔ **zenedo 空气质量**（date）：时间关联，同日期对比校验 AQI 口径一致性

## 5. 数据规模与合规说明

- **本子项目数据源总原始规模**：约 240 KB（空气质量、环境指数.zip 解压后约 800 KB）
- **是否满足单源≥200MB**：否（本包均为辅助小数据，非主数据源）
- **是否涉及个人敏感信息**：否
- **是否遵守服务条款与robots**：是（开放数据 CC0 + 政府公开数据，无爬取行为）
- **其他说明**：① 包名「空气质量、环境指数」中，「环境指数」广义综合指数无法由本包数据计算，狭义 EI 可由 AQI 近似（zenedo 提供 US-AQI / European-AQI，生态环境局提供中国 AQI）；② 空气质量为城市级单条日序列，无分区数据；③ 污染物单位与 AQI 口径需在 E 清洗阶段统一并交叉校验
