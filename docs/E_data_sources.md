|---|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| 来源 | 孙道千, 孙维然, 程小燕, 王洁, 成方妍. 上海城市绿地的植被韧性数据集（2001–2022）研发[J]. 全球变化数据学报, 2025, 9(1): 52–58. DOI:10.3974/geodp.2025.01.07；数据 DOI:10.3974/geodb.2024.12.04.V1（全球变化科学研究数据出版系统 http://www.geodoi.ac.cn）                              |

| 时间范围 | 植被韧性：2001–2022 年（MODIS MOD13Q1 NDVI，16 天合成）；绿地占比：2015–2024 年（Dynamic World 众数地类）；研究区边界：2024 年（高德行政区范围）                                                                                                                    |
| 采集时间 | 2026-10-16                                                                                                                                                                                                                |
| 许可/使用说明 | 开放数据，免费浏览下载；**必须按引用格式标注来源**；摘取部分记录创作新数据须遵循 10% 引用原则；增值/再传播须与编辑部签书面协议                                                                                                                                                      |
| 主要字段/图层 | ① `1_StudyArea/sh.shp` 研究区范围（单 POLYGON，10 个 part）；② `2_Green_R/GREEN_R.TIF` 绿地占比（%）；③ `3_STL_AR1/STL_AR1.TIF` 韧性·简化STL的AR(1)（负值=模型不适用，占14.4%）；④ `4_V2_AR1/V2_AR1.TIF` 韧性·滚动平均+谐波的AR(1)（越负越强）；⑤ `5_V2_VAR/V2_VAR.TIF` 韧性·同流程方差（越负越强） |

| 可关联数据源 | 绿化数据（区级，可交叉验证绿地口径）；空气质量（若取区级聚合可对齐）；行政区划（区界 shapefile，做分区汇总时必需）                                                                                                                                                            |
| 关联方式 | 空间（网格→行政区聚合）/ 时间（年度序列）                                                                                                                                                                                                    |
| 采集脚本 | 暂无（网页下载，未写爬虫）                                                                                                                                                                                                             |
| 备注 | 栅格为 UTM 49N，与边界 shapefile（WGS84 地理坐标）坐标系不一致；NoData 哨兵值与数据类型在两两栅格间不一致（float32/-3.4e38 vs float64/-1.8e308）；四幅栅格空间掩膜完全一致。      |

## 5. 数据规模与合规说明

- 本成员数据源总原始规模：约 924 KB（4 个 .xls 约 112 KB + 植被韧性数据集约 812 KB）
- 是否满足单源≥200MB：**否**——年鉴 4 表约 112 KB、植被韧性数据集约 812 KB。注：文件体积小不等于数据量小，韧性数据集含 881,136 个栅格单元数值（220,284 像元 × 4 层）。
- 是否涉及个人敏感信息：否
- 是否遵守服务条款与robots：是（公开数据网页正常导出，无高频抓取）
- 其他说明：年鉴如需历史年份数据（2019–2023），可按同样方式从对应年份年鉴获取；4 幅栅格为 2001–2022 年（GREEN_R 为 2015–2024 年）时序计算所得的汇总指标图层，不含逐年切片，如需逐年变化需回到 MODIS NDVI 原始数据自行计算。
