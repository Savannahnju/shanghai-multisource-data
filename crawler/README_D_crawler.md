# README — D 数据采集说明

## 采集情况

D（Q2：环境质量 × 植被）的 4 个数据源均为**现成数据直接获取**，**无爬虫脚本**：

| 数据源 | 获取方式 | 说明 |
|---|---|---|
| 环境质量（2017 降尘量/PM2.5、2024–2025 空气质量） | 政府公开数据 / 组内提供 | 无爬取 |
| 植被（绿地占比、植被韧性栅格） | 开放数据集下载 | DOI 10.3974/geodb.2024.12.04.V1 |
| 统计年鉴（绿地面积、人口密度） | 政府公开数据 / 组内提供 | 无爬取 |
| 行政区划 shp | 政府公开数据 / 组内提供 | 无爬取 |

## 结论

- 本成员不涉及 API 调用、网页抓取或限速/robots 问题，故 `crawler/` 目录无采集脚本。
- 各数据源来源、许可、校验值详见 `docs/D_data_sources.md`。
