## 目录结构

```
project/
├── data/             # 数据（抽样/索引）
│   ├── raw/          # 原始数据的抽样/索引
│   ├── cleaned/      # 清洗后数据的抽样/索引
│   └── integrated/   # 跨源融合后的核心数据
├── crawler/          # 数据采集代码
├── processing/       # 清洗、规范化、实体/时间/空间对齐
├── analysis/         # 分析与数据挖掘
├── visualization/    # 可视化代码与结果
├── docs/             # 数据源、方法、图表说明等
├── data_sources.md   # 数据来源与 provenance
├── AI_USAGE.md       # AI 使用记录、心得与反思
└── README.md         # 一键或分步复现说明
```
