# B · Q1 分析脚本 README

> 研究问题：**城市环境质量是否与地铁客流量（2017 年）有关？**
> 负责人：B。本脚本为**统计分析 + 回归**（描述统计、Pearson 相关、OLS 回归 M1–M5）；
> 可视化已拆分到 `B_Q1_visualization.py`。

|---|---|---|---|

## 2. 运行环境与命令

- Python 3.10+，依赖：`pandas`、`numpy`、`scipy`、`statsmodels`、`matplotlib`（仅旧版出图部分使用）。
- 前置：先运行 `fuse_environment_metro.py` 生成融合宽表。

```bash
cd Q1_融合分析/可复现脚本
python -I analyze_q1.py
```

> 输入/输出路径在脚本顶部参数化（`BASE = 脚本所在目录`），结果统一写入 `output/analysis_summary.txt`。

| 类型 | 路径（相对 `Q1_融合分析/`） | 说明 |

## 4. 分析内容

| 模块 | 方法 | 说明 |
|---|---|---|
| 1. 描述统计 | mean/std/min/中位/max | 8 个数值列，52 观测 |
| 2. 相关分析 | Pearson r + p 值 | 面板相关（n=52）+ 截面相关（区级 5–8 月均值，n=13） |
| 3. 回归 | OLS，稳健标准误 HC1 | M1 双变量 → M2 加控制变量 → M3 区固定效应 → M4 剔除青浦区 → M5 对数因变量 |

## 5. 关键结果

**描述统计（n=52）**

| 变量 | 均值 | 标准差 | 最小 | 最大 |
|---|---:|---:|---:|---:|
| 降尘量（t/km²·月） | 4.18 | 0.69 | 2.9 | 5.8 |
| PM2.5（μg/m³） | 35.77 | 4.17 | 29.0 | 46.0 |
| 客流强度（人次/站·月） | 1,423,479 | 614,022 | 694,556 | 2,665,782 |
| 站点数（个） | 23.0 | 19.8 | 1 | 85 |

**关键变量两两相关（面板 n=52）**

| 关系 | r | p | 解读 |
|---|---:|---:|---|
| 客流强度 ~ PM2.5 | +0.047 | 0.739 | 不显著 |
| 客流强度 ~ 降尘量 | −0.211 | 0.134 | 不显著 |
| 地铁总客流 ~ PM2.5 | −0.487 | 0.0003 | 显著负相关（疑为城市化混杂） |

**OLS 回归（HC1 稳健标准误，因变量=客流强度）**

| 模型 | 设定 | R² | 环境变量结论 |
|---|---|---:|---|
| M1 | pm + dust | 0.046 | 均不显著 |
| M2 | 加 temp + rain + wd | 0.103 | 均不显著 |
| M3 | 再加区固定效应 | 0.996 | 降尘量 −30,328（p=0.048）；rain −1,417（p=0.006）；wd +49,077（p=0.005）；pm 不显著 |
| M4 | M2 剔除青浦区（1 站） | 0.041 | 全部不显著 |
| M5 | 对数因变量 | 0.081 | 全部不显著 |

## 6. 结论（回答研究问题）

**城市环境质量与地铁客流量之间未发现稳健、显著的关联。** 证据：

1. 面板相关与 M1–M2 回归中，客流强度对 PM2.5、降尘量均不显著；
2. M3 区固定效应中降尘量的边际显著（p=0.048），在 M4（剔除单站离群区青浦区）与 M5（对数变换）后消失，说明该结论不稳健；
3. 地铁总客流与 PM2.5 的负相关（r=−0.487）更可能由**城市化混杂**解释：中心城区站点密集、客流高，同时 PM2.5 反而偏低。

## 7. 复现说明

- 脚本只读融合宽表，不修改原始数据；结果为确定性文本，可重复运行（幂等）。
- 回归采用 HC1 稳健标准误，区固定效应以 `C(dist)` 加入；随机种子不涉及（无随机操作）。
- 若重跑 `fuse_environment_metro.py` 后融合宽表一致，则 `analysis_summary.txt` 逐字节一致。
