# integrated_data（GitHub 上传样本）

> 研究问题：城市环境质量是否与地铁客流量（2017 年）有关？
> 本目录为**上传 GitHub 的最小可复现样本包**，仅含「代表性样本数据 + 元数据 / 数据规模统计 / 文件清单与校验值 + 数据处理脚本」，不包含原始大文件。

## 3. 元数据（数据字典）

| 字段 | 类型 | 单位 | 说明 |
|---|---|---|---|
| 区名 | str | — | 16 区标准名（实际 13 个有站区） |
| 月份 | int | 5/6/7/8 | 2017 年 5–8 月 |
| 降尘量 | float | t/(km²·月) | 该区该月降尘量（单位按领域惯例推定） |
| PM2.5 | float | μg/m³ | 该区该月 PM2.5 月均浓度 |
| 地铁总客流 | int | 人次 | 该区该月进出站客流之和 Σ(inFlow+outFlow) |
| 地铁日均客流 | float | 人次/日 | 总客流 ÷ 有效天数 |
| 客流强度 | float | 人次/站·月 | 总客流 ÷ 站点数 |
| 站点数 | int | 个 | 该区地铁站点数 |
| 有效天数 | int | 天 | 该区该月有效运营天数 |
| 工作日数 | int | 天 | 该月有效工作日数（全市一致） |
| 月均温 | float | ℃ | 该月日均气温月均值（全市一致） |
| 月总降雨 | float | mm | 该月日降雨量合计（全市一致） |

- 编码：UTF-8 with BOM（utf-8-sig），逗号分隔，Excel 可直接打开。
- 数据来源：地铁客流/站点/气象/工作日历出自 MetroFlow 开源数据集（MIT License，引用 Sun et al., *Scientific Data* 12 (2025)）；环境质量出自 `2017年各区降尘量与PM2.5月均浓度.xlsx`。

## 4. 数据处理脚本说明

`fuse_environment_metro.py` 为可复现融合脚本，输入/输出/字段变化/口径规则已写入脚本头部注释。运行命令：

```bash
python -I fuse_environment_metro.py
```

**重跑前置条件**（原始数据未随包上传，需按如下结构放置）：

```
上海地铁客流量2017/                     # 脚本 BASE = 脚本所在目录的上一级
├── metroData_InOutFlow.csv             # 217 MB，主数据
├── B_数据清洗要求/站点_区映射.csv
├── 2017年各区降尘量与PM2.5月均浓度.xlsx
└── 天气&工作日/{workday_calendar.csv, shanghai_weatherHourly.csv}
```

脚本会输出 `output/` 下的 4 个 CSV（含 `fused_environment_metro_2017.csv`，与本包样本内容一致）与 `fusion_log.txt`。
