# README_C_integrate —— Q2 融合数据说明

> 成员：C
> 核心问题（Q2）：利用多源异构数据，探究上海城市环境质量与产业结构（POI 各产业比例 / 聚集数量）有何相关性
> 产出：`data/integrated/integrated_C_Q2_sample.csv`（16 行 × 36 列，约 4 KB）

---

## 1. 文件

| 文件 | 说明 |
|---|---|
| `processing/C_Q2_integrate.py` | 融合脚本：把四类信息按 `adcode` 合并为一张宽表并做完整性校验 |
| `data/integrated/integrated_C_Q2_sample.csv` | 融合结果（分析基座），UTF-8-SIG，中文表头 |
| `analysis/C_Q2_analysis.py` | 上游流水线，产出本脚本读取的 4 张阶段结果表 |

## 2. 运行

```powershell
# 前置：先跑分析流水线，产出 analysis/output/ 的阶段表
set SH_BASE=E:\大数据大作业_上海城市
python analysis\C_Q2_analysis.py

# 再生成融合表
python processing\C_Q2_integrate.py
```

依赖：`pandas`。本脚本不重算模型，只做跨表对齐与字段组织，因此与 `C_Q2_analysis.py` 的数值完全一致。

## 3. 融合方式

统一键为 **`adcode`**（民政区划码），由 `data/raw/raw_C_district_sample.geojson` 的 `properties.adcode` 提供，
并与各阶段表的 `区名` 逐一对齐，4 次合并均使用 `validate="1:1"`，任一键不匹配或重复会直接报错。

| 融合块 | 来源表 | 关联方式 |
|---|---|---|
| 空间属性与产业结构 | `analysis/output/01_产业结构指标.csv` | `区名` ↔ geojson `district` |
| 环境质量（两年均值） | `analysis/output/02_环境质量刻画.csv` | `区名` |
| 机制代理变量 | `analysis/output/04_机制变量表.csv` | `区名` |
| 聚类结果 | `analysis/output/06_Kmeans聚类.csv` | `区名` |

前置关联来自上游分析：POI 点（WGS-84）与区多边形做空间连接得到 `区名`，空气质量取 2024-01—2025-12
共 24 个月的区级均值，最终三源在同一个 16 行键上收敛。

## 4. 字段分组（36 列）

| 列组 | 字段 | 来源/口径 |
|---|---|---|
| 键 | `adcode`、`区名` | 区界 geojson |
| 空间与规模 | `面积_km2`、`距市中心_km`、`原始POI总数_条`、`产业POI数_条`、`POI密度_个每km2` | 区界面积 / 质心距离 / POI 空间连接 |
| 产业结构 | `占比_交通运输仓储` … `占比_金融业`（12 列）、`Shannon多样性`、`HHI集中度`、`PC1`、`PC2` | 剔除`居住地址标识`后重新归一化；CLR-PCA |
| 数据挖掘结果 | `Kmeans簇`、`主导产业`、`主导产业占比` | CLR 空间 K-means（k=3，轮廓系数最优） |
| 机制代理 | `扬尘源数`、`物流源数`、`汽修源数`、`商务住宅数` | POI 大类计数 |
| 环境质量 | `PM2.5_ug_m3`、`道路PM10_ug_m3`、`O3_ug_m3`、`AQI优良率_pct` | 区 × 年月 384 条 → 24 个月算术平均 |
| 对齐标记 | `POI年份`=2025、`空气质量窗口`=`2024-01~2025-12` | 时间对齐声明 |

## 5. 为什么是 16 行而不是抽样

Q2 的空间分析单元就是 16 个市辖区，16 行即**最小完整分析集**，整表仅 4 KB，再降采样会破坏
"每区一条记录"的分析前提。真正需要抽样控制的是原始明细（POI 1,339,912 条、空气 384 条、
原始数据约 253 MB），这些明细不入仓库，仓库只保留本融合表与 `data/raw/` 的抽样样本。

## 6. 校验

脚本内置 4 项断言，全部通过：

1. 行数 = 16，`adcode` 唯一；
2. 全表无缺失值（`isna().sum() == 0`）；
3. 12 类占比每行之和与 100% 的偏差 < 0.1（成分数据闭合性）；
4. `PM2.5_ug_m3` 区间落在 25.3—30.5，与 `analysis/README_C_analysis.md` 的区间极差 5.2 一致。

## 7. 已知约束

- `PC1`/`PC2`/`Kmeans簇` 是**模型派生列**，只能随 `C_Q2_analysis.py` 的结果更新，不可单独手工改动；
- 空气质量为 24 个月均值，已抹平季节波动，不代表任一年份的瞬时浓度；
- POI 为 2025 年截面，融合表无时间维度，不能做面板或因果推断；
- `cleaned_Data/区界.gpkg` 几何与区名错配，`adcode` 一律取自 geojson，不取 gpkg；
- 融合表只覆盖 Q2 所需字段，不含 Q1（地铁客流）与 Q3（绿地）的变量。
