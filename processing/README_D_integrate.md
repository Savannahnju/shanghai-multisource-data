# Q1 数据融合脚本 README

> 研究问题：**城市环境质量是否与地铁客流量（2017 年）有关？**
> 负责人：B（地铁客流侧）。脚本把地铁客流（站点 × 10 分钟）、站点→区映射、2017 年环境质量（区 × 月降尘量 / PM2.5）、工作日历与逐小时气象，融合为一张「区 × 月」分析宽表。

---

## 1. 脚本清单

| 脚本 | 作用 | 输入 | 输出 |
|---|---|---|---|
| `fuse_environment_metro.py` | 数据融合（可复现） | 4 个原始文件 + 站点→区映射 | `output/` 下 4 个 CSV + 日志 |
| `analyze_q1.py` | 统计分析 + 回归 + 可视化 | `output/fused_environment_metro_2017.csv` | `figures/` 下 4 张图 + `output/analysis_summary.txt` |

## 2. 运行环境与命令

- Python 3.10+，依赖：`pandas`、`numpy`、`matplotlib`、`scipy`、`statsmodels`、`openpyxl`。
- 运行顺序：**先融合，后分析**。

```bash
# 在 Q1_融合分析/ 目录下执行
python -I fuse_environment_metro.py     # ① 数据融合，产出 output/*.csv
python -I analyze_q1.py                 # ② 分析与出图，产出 figures/*.png
```

> 输入路径在脚本顶部 `BASE = Path(__file__).resolve().parents[1]` 参数化，指向 `上海地铁客流量2017/`；如需迁移目录，只需保证该相对层级不变。

## 3. 输入文件

| # | 文件（相对 `上海地铁客流量2017/`） | 内容 | 规模 | 用途 |

| 1 | `metroData_InOutFlow.csv` | 地铁进出站客流（站点 × 10 分钟） | 3,788,892 行 × 13 列 | 主数据源，聚合到区 × 月 |

## 5. 字段变化（原始 → 融合后）

| 操作 | 变化 | 数量依据 |
|---|---|---|
| 剔除采集不完整日 | 20170504/0508/0509/0616/0627/0628 整日删除 | -184,824 行 |
| 剔除市外站点 | 11 号线昆山段 3 站（Huaqiao / Guangming Road / Zhaofeng Road） | -35,802 行 |
| 站点 → 区聚合 | 站点级 10 分钟 → 区级月度求和 | 3,788,892 → 52 行 |
| 时间对齐 | 仅保留 5–8 月 | 4 个月 |
| 空间对齐 | 仅保留 13 个有站点区（奉贤/金山/崇明无站点，不补 0） | 13 区 |
| 环境宽表转长表 | 16 区 × 12 月 → 区名 × 月份（降尘量 / PM2.5 两列） | 5–8 月 |
| 派生指标 | 新增 地铁日均客流 = 总客流 ÷ 有效天数；客流强度 = 总客流 ÷ 站点数 | — |

## 6. 融合宽表数据字典

| 字段 | 类型 | 单位 | 说明 |
|---|---|---|---|
| 区名 | str | — | 16 区标准名（实际 13 个有站区） |
| 月份 | int | 5/6/7/8 | 2017 年 5–8 月 |
| 降尘量 | float | t/(km²·月) | 该区该月降尘量（单位按领域惯例推定） |
| PM2.5 | float | μg/m³ | 该区该月 PM2.5 月均浓度 |
| 地铁总客流 | int | 人次 | 该区该月进出站客流之和 Σ(inFlow+outFlow) |
| 地铁日均客流 | float | 人次/日 | 总客流 ÷ 有效天数 |
| 客流强度 | float | 人次/站·月 | 总客流 ÷ 站点数（**推荐主因变量**） |
| 站点数 | int | 个 | 该区地铁站点数（供归一化/诊断） |
| 有效天数 | int | 天 | 该区该月有效运营天数（剔除不完整日后） |
| 工作日数 | int | 天 | 该月有效工作日数（全市一致） |
| 月均温 | float | ℃ | 该月日均气温的月均值（全市一致） |
| 月总降雨 | float | mm | 该月日降雨量合计（全市一致） |

## 7. 口径与校验

- 主键：**区名 + 月份**；merge 为内连接，校验通过 13 区、52 行、无重复区月、无缺失、无笛卡尔积。
- 客流一律用 `inFlow/outFlow` 总量，不用 C/HBO/NHB 分量；环境 2024–2025 sheet（Sheet3）已排除，不进入本分析。
- 编码：所有输出 CSV 为 **UTF-8 with BOM（utf-8-sig）**，Excel 双击打开不乱码。
- 复现性：脚本输入路径参数化、原始文件只读、抽样固定随机种子（本流程无抽样）。
