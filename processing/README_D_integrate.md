# README — D Q2 数据融合脚本

## 脚本

- `D_Q2_integrate.py`：把环境质量、植被、年鉴三类清洗后数据按「区名」融合为区级宽表。

## 输入（D/data/cleaned/）

- `空气_区×年月.csv`（环境质量，区 × 月，2024–2025）
- `栅格分区统计原始结果.csv`（植被分区统计，16 区）
- `绿地与植被_区级明细.csv`（年鉴绿地面积、人口密度，16 区）

## 输出

- `D/data/cleaned/主表_区级宽表.csv`（16 区 × 17 列）

## 运行命令（在项目根目录执行）

```bash
python D/processing/D_Q2_integrate.py
```

脚本基于自身位置自动定位数据，从任意目录运行均可。

## 依赖

pandas

## 字段变化说明

- 环境质量：`空气_区×年月.csv` 按「区名」聚合为区级——`AQI优良率(%)`/`PM2.5(μg/m³)`/`O3(μg/m³)`/`道路PM10(μg/m³)` → 重命名为 `AQI优良率`/`PM2.5`/`O3`/`道路PM10`（2024 年均），另生成四个 `*_两年均值` 列（2024–2025）。
- 植被：`栅格分区统计原始结果.csv` 抽取 `遥感绿地占比均值_%`→`绿地占比`、`STL_AR1均值_剔除负值`→`韧性_STL_AR1`、`V2_AR1均值`→`韧性_V2_AR1`、`V2_VAR均值`→`韧性_V2_VAR`、`有效绿地像元数`。
- 年鉴：`绿地与植被_区级明细.csv` 抽取 `绿地面积(公顷)`→`绿地面积`、`人口密度(人/平方公里)`→`人口密度`。
- 融合键：`区名`（16 区），左连接合并；植被为空的三区（徐汇/静安/普陀）绿地占比等为 NaN。
